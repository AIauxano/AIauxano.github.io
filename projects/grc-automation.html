Automated Control Evidence with Python

Re-performed the offboarding test in code across the full population and extended it to AWS IAM, which surfaced a terminated admin's access key still in use.

SOC 2 CC6.2Continuous control monitoring

Skills shown

  • Python (pandas)
  • Evidence automation
  • Reconciliation

Artifacts

  • check_evidence.py
  • hr_terminations.csv
  • okta_users.csv
  • iam_credential_report.csv

The situation

Manual control tests sample a few items a year. Automation tests every item, every week, and leaves a reproducible evidence trail.

Approach

  1. Loaded HR, Okta and AWS IAM exports into pandas.
  2. Computed business-day lag, still-active accounts, post-termination logins and orphan accounts.
  3. Flagged console users without MFA and access keys older than 90 days.
  4. Reconciled with the manual workpaper and hashed each input file.

Analysis

Findings

  • The script matched the manual test exactly.
  • inovak's AWS key shows privileged access outside the identity provider: a design gap and a likely incident.

Recommendations

  • Bring all AWS human access under SSO; run the script weekly and keep hashed evidence.
