SOC 2 Type II Audit Readiness

Ran an auditor's request list, prepared a control owner for a walkthrough, and wrote management responses and a remediation plan that fix root causes.

AICPA Trust Services CriteriaSOC 2 Type II

Skills shown

  • PBC management
  • Walkthrough preparation
  • Management responses
  • POA&M

Artifacts

  • Lab workbook (T_PBC_Tracker, T_Walkthrough, T_POAM)

The situation

The auditor sent 12 requests for the January to June 2027 window, and draft exceptions followed from the control testing.

Approach

  1. Assigned an owner, due date and evidence type to each request and wrote the likely gotcha.
  2. Reviewed evidence before release: full period, system-generated, complete population, in scope.
  3. Coached the VP Engineering for a change-management walkthrough, including the question teams miss: are console and Terraform changes covered?
  4. Wrote management responses and a dated POA&M.

Analysis

RequestGotcha caught before sending
PBC-03 terminationsHR report excludes contractors; reconcile to Okta first
PBC-04 access reviewsExports alone fail; reviewer decisions and removal tickets required
PBC-11 board minutesFails if security never reached the agenda

Findings

  • Strong responses name the system cause, not a person.
  • A lookback on post-termination access belongs in the remediation plan.

Recommendations

  • Track every request in one tracker with overdue flags; never send unreviewed evidence.
